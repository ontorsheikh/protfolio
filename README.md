# Animated Portfolio (React + Vite)

A fast, animated portfolio template built with **React**, **Vite**, and **Framer Motion**.

## 🚀 Run locally

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (`http://localhost:5173` by default).

## 🛠 Customize

- Update your name / title in `src/App.tsx` (Hero + footer)
- Add / edit projects in the `projects` array inside `src/App.tsx`
- Tweak styles in `src/App.css`

## 🧩 Notes

- Animations are handled with **Framer Motion** (`framer-motion` dependency)
- The project is already configured to build via `npm run build` and preview via `npm run preview`
